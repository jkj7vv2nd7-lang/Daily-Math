日めくり数学（2026年11月分）
================================

東京出版『大学への数学』の名物コーナー「日々の演習」にヒントを得た、
日付入りの数学問題を毎日楽しむアプリです。


2026年11月分：1日3問 × 30日 = 全90問
・古典パズル（鶴亀算・植木算・魔方陣・川渡り・カプレカ数など）
・高校入試レベル（計算・方程式・関数・確率・図形など）
・大学入試レベル（整数・数列・微積分・ベクトル・確率など）
全問に模範解答と「添削ポイント」つき。


index.html をブラウザで開くだけで使えます。
- 日付を選んで3カテゴリーの問題カードをタップ
- 解答スペースに指やペンで手書き計算ができます（自動保存）
- 答えが数値などで決まる問題は「判定する」で自動判定
- 「解答・解説を見る」で模範解答と添削ポイントを確認し、
◎（正解）／△（一部正解）／×（不正解）で自己採点できます
- カレンダーで月の進み具合がひと目で分かります


index.html と icon.png の2ファイルを、リポジトリのルートに
両方アップロードしてください（icon.png がホーム画面用アイコンです）。


Safari でページを開き、共有ボタン →「ホーム画面に追加」。
日めくりカレンダーのアイコンで表示されます。


手書きの解答・採点記録は、その端末のブラウザ内に保存されます。
別の端末とは同期されません。


12月分以降は、月ごとに新しい問題集が用意されます。
